# 0006 · 网页画布界面（MVP）

状态：已决定（MVP）

日期：2026-10-26

桌面端暂不做（[0005](0005-agent-adapters-and-mcp.md)“范围调整”），但只有命令行客户端时看不到画布，也无法拖动、引用、预览。本文先做一个在本机浏览器里打开的界面，界面代码按将来放进 Electron 渲染层的方式编写。

## 目标与范围

第一版要能在浏览器里完成一次完整创作：看画布、整理节点、引用节点给 Agent 发消息、看回复流式出现、看生成结果回填。

| 做 | 不做（以后） |
|---|---|
| 画布：平移、缩放、选择、拖动、调整大小、删除、撤销与重做 | 手动连线、编组、多选对齐 |
| 节点：图片、视频（可播放、拖进度）、文本（可编辑） | 组合组件（四格漫画等） |
| 拖入本机图片或视频导入到画布 | 真实生成 Provider 接入 |
| 会话：列表、新建（选 Agent 种类）、记录、流式回复、停止 | 看板、任务管理 |
| 发消息时引用选中的节点 | 审批界面（0005 仍为自动回答） |
| 生成任务状态：进行中、失败、无产物，显示在目标节点上 | 成本统计 |
| 修订冲突提示：别人改过时提示并以最新内容为准 | 多人光标、协同编辑 |

## 结构

```
浏览器（canvas-ui、workbench-ui）
   │ WebSocket：JSON-RPC 原样转发     HTTP：页面、素材文件、上传
   ▼
apps/web（本机网页宿主，承担将来 Electron 主进程的角色）
   │ 本机 socket + NDJSON，以界面身份连接（读 run/studiod.token）
   ▼
studiod（不变）
```

- 沿用 0004“渲染层不直接连 studiod，经主进程转发”：网页宿主就是这个“主进程”。studiod 不开 HTTP 端口，攻击面不变。
- 界面包只依赖 `protocol` 和一个注入的 `call / subscribe` 接口，不知道下面是 WebSocket 还是 Electron IPC。将来换成桌面端时只替换宿主，界面包不改。
- 每个浏览器标签页对应宿主到 studiod 的一条界面连接，订阅、去重、断线补发都沿用现有的 `events.subscribe` 与 `afterSeq`。

## 本机安全

本机网页服务会被本机其他程序和浏览器里的其他网页访问，必须防住：

- 只监听 `127.0.0.1`，端口随机。
- 宿主启动时生成随机令牌，打开的地址形如 `http://127.0.0.1:<port>/#t=<令牌>`；页面读取后从地址栏抹掉。WebSocket 握手和每个 HTTP 请求都要带令牌。
- 校验 `Host` 必须是 `127.0.0.1:<port>`（防 DNS 重绑定），WebSocket 校验 `Origin` 与本页同源（防其他网页跨站连接）。
- 素材文件只按 `assetVersionId` 提供：宿主先经 `asset.get` 向 studiod 取路径，不接受任意路径。
- 上传先写入宿主的临时目录，再以该路径调用 `asset.import`，完成后删除临时文件。

## 素材访问

`AssetVersionView.url` 是 `file://` 地址，浏览器加载不了。宿主提供 `GET /assets/<assetVersionId>`，支持 Range 请求（视频拖进度需要），内容寻址的 blob 不会变，可长期缓存。界面一律通过这个地址取素材。

## 技术选型

| 项目 | 选择 | 理由 |
|---|---|---|
| 界面框架 | React + TypeScript | Electron 渲染层直接复用；生态成熟 |
| 构建 | Vite | 开发热更新；产物是静态文件，由宿主提供 |
| 画布 | React Flow（`@xyflow/react`，MIT） | 已确认。平移、缩放、选择、拖动、缩放手柄现成可用；节点就是普通 React 组件，`<video>` 和文本编辑都是原生元素。以后要做连线也有现成能力。备选：自己用 CSS transform 实现，代码量多一倍左右 |
| 状态 | 一个按事件归并的客户端仓库（快照 + 按 seq 应用事件），不引入状态管理库 | 后台已经保证了事件顺序与去重，客户端只需要归并 |
| 宿主 | Node 的 `http` + `ws` | 依赖最少 |

注：tldraw 的 SDK 用于生产环境需要商业授权，不选。

## 界面布局

```
┌────────────────────────────────────────────┬──────────────────┐
│ 空间名 · 连接状态                          │ 项目名 ＋新建  │
├────────────────────────────────────────────┼──────────────────┤
│                                            │ 会话卡片（手风琴）│
│                画布                         │  · 用户消息      │
│  [文本] [图片] [视频]                       │  · Agent 回复（流式）│
│  生成中的目标节点显示进度/失败               │  · 工具调用（折叠）│
│                                            ├──────────────────┤
│                                            │ 已引用：节点 ×3   │
│                                            │ [输入框]   [发送]│
└────────────────────────────────────────────┴──────────────────┘
```

- 会话面板可用右上角按钮或 Cmd/Ctrl + \ 收起为 44px 会话竖条，点击会话图标展开并切换；左边缘可拖动调宽（最小 300px、最大半个视口，窄视口优先保留最小宽度），宽度与收起状态保存在 localStorage，收起不打断回合或流式回复。
- 项目区固定显示空间名、会话总数与运行数，新建菜单只提供 Codex / DeepSeek，支持方向键、Enter 和 Esc。会话按创建时间堆叠为卡片，徽标保留 Agent 色；最多展开一个，点击展开卡片头可全部收起。选中会话变化或画布发来引用时自动展开，运行卡片可直接停止。空间不足时卡片头滚动，展开卡片至少保留 320px。
- 在画布上选中节点，点“引用”加到输入框上方；发送时作为 `refs` 传入。待发送与用户消息正文上方复用引用缩略图：图片 / 视频 48px、文本两行、空槽位类型图标、删除节点占位；超过六个时用 +N 展开。点击有效引用选中节点并在当前缩放下平滑居中，删除引用不触发定位。按 `latest-at-execution` 展示主槽位当前内容，App 负责解析资源地址，workbench-ui 不依赖 canvas-ui。
- 连续工具调用及结果合成默认收起的工具组，以第一条 itemId 保持展开状态；用户、助手文本、通知与流式草稿作为分隔。摘要显示工具数、工具名与进行 / 失败状态；展开后逐项查看输入摘要，再展开单项查看完整输入和结果。停留记录底部时，新增内容和工具折叠继续贴底；主动上滚后保留阅读位置。
- 文本节点双击编辑，失焦提交 `slot.setText`（带 `expectedRevision`）；返回 `revision_conflict` 时提示“已被其他人修改”，保留草稿供复制，画面换成最新内容。
- 拖动和调整大小在松手时提交 `node.layout`（不带修订号，后写者生效，0003）。
- Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 或 Ctrl+Y 重做，经 `canvas.undo` / `canvas.redo` 提交；没有可操作记录或操作失败时显示提示。输入框、文本域和可编辑内容保留浏览器自己的撤销与重做。

## 实现步骤

1. **宿主与连接**：`apps/web` 起 HTTP 和 WebSocket，转发 JSON-RPC，校验令牌、Host、Origin；提供 `/assets/<id>`。命令行 `pnpm dev:web` 启动并打印地址。
2. **只读画布**：订阅、快照、事件归并；渲染三种节点；平移、缩放；断线重连带 `afterSeq` 补发。
3. **画布编辑**：拖动、调整大小、删除、文本编辑与冲突提示、拖入导入。
4. **会话面板**：列表、新建、记录分页、流式回复、发送（带引用）、停止。
5. **生成状态**：在目标节点上显示进行中、失败、无产物；新建节点的结果出现时高亮。

第 5 步的做法：
- `JobView` 增加 `targets`，列出每个产物位置的交付目标（槽位，或新建节点及其锚点 `nearNodeId`）与交付状态。`job.stateChanged` 的载荷带完整的 `job` 视图，`binding.stateChanged` 带目标节点 `nodeId`，界面不必再读。
- 进行中的任务在目标节点（新建节点的任务在锚点节点）上显示“生成中”；找不到节点的只计入页头。
- 失败、结果未知、冲突、目标已删除、无产物的任务留在节点上提示，用户关闭为止；只在本页记住，刷新后不再显示（快照只含进行中的任务）。
- 交付事件到达时节点描边亮一下；刷新或重新取快照后不重复。

每一步都可以单独验收。宿主的安全校验、事件归并写单元测试；界面用 Playwright 驱动本机 Chrome 做一条端到端用例（打开、拖动、发消息、看到回填）。

## 画布来源连线与小地图

- 当前槽位的生成来源以虚线箭头从输入节点指向产物节点；两端仍在画布上才显示，多槽位重复来源只画一条。连线在节点下方，只读、不可选中或删除；删除节点、手动改写槽位后随事件更新。
- 生成结果先在锚点四周按右、下、左、上寻找空位，四边都占用才按 NODE_GAP 外扩；按矩形边距选最近候选，同距仍按上述顺序，达到上限则回退到现有内容右侧。无锚点行为不变。
- 右下角小地图支持拖动平移和滚轮缩放，文本、图片、视频以深浅灰区分，生成中用 warn，问题节点用 danger；可收起，开关保存在浏览器 localStorage。下方提供缩小、缩放百分比（点击恢复 100%）、放大和适应画布，不再显示 React Flow Controls。

## 手动创建与生成节点

画布底部居中工具栏以图标提供“文本”“生图”“生视频”“上传”（各有可访问名称和悬停提示），在当前视口中心创建节点；上传走原有文件导入回调。生成节点沿用 image/video 类型，含 main 媒体槽位和 prompt 文本槽位，main 始终排在前面；导入的单槽位媒体节点显示不变。

文本、图片、视频的图标和类型名称显示在卡片外上方，卡片内不再显示标题栏。空媒体用对应 SVG 图标占位，空文本显示“双击开始编辑”。

体验优化第一批（2026-10-29）：
- 滚轮经过节点时默认平移画布。只有节点选中且内容确实可滚动时由节点内部滚动，滚到顶或底后交还画布；正在编辑的文本框保持原样。
- 选中节点时，与之直接相连的来源与参考连线加粗并使用强调色，其余连线变淡；颜色取主题变量，过渡遵守 `prefers-reduced-motion`。
- 视频节点默认宽 320px，高度按视频宽高比计算，未知时按 16:9。只影响新建、导入与生成；已有节点保持原尺寸，不做迁移。

恰好选中一个生成节点时，使用 React Flow NodeToolbar 在卡片下方显示提示词浮层；其宽度跟随节点，至少 420px，不占节点内容高度。浮层顶部显示 `NodeView.inputs` 对应的参考缩略图或文本卡片，每项可移除。点“添加参考”进入挑选模式，点击另一个画布节点将其加入输入，保持目标节点选中；Esc 取消。失焦或 Cmd/Ctrl+Enter 按编辑开始时的修订提交，冲突沿用文本节点的提示与草稿复制机制。空提示词禁用生成；点击生成先保存草稿，再以 prompt 和参考节点的 main 槽位为输入、main 为输出目标调用 generation.submit。底部显示当前服务、模型与参数摘要，可打开模型选择器；默认 mock Provider 返回占位图或视频。浮层禁止拖动画布及编辑键盘事件传播；滚轮只在浮层内容可滚动时由浮层处理，滚到顶或底后交还画布平移。

单选任意节点时，右侧 ⊕ 菜单提供生图、生视频；新生成节点的 inputs 包含当前节点。单选生成节点时，左侧 ⊕ 新建文本并加入当前生成节点的 inputs。新节点与当前节点间隔 80 画布单位，遇到已有节点时向下寻找空位；创建后选中新节点并将视口居中。以上操作经注入的 `onExtend` 回调完成，参考修改经 `onSetInputs` 完成，UI 不直接发送 RPC。

待生成输入关系以更淡的细实线箭头从参考节点指向生成节点，复用来源连线的边选择逻辑。相同节点对同时存在已生成来源关系时，只显示来源虚线；删除节点后不显示其参考卡片或连线。

生成中、失败和交付高亮复用现有节点状态。生成期间仍可再次点击，新请求接管 main 槽位，旧请求结束时按既有语义提示回填冲突，不提供取消。

## 视觉风格

第一版用中性灰黑主题：画布底色 `#141414`，节点卡片 `#262626`，浮层和工具栏使用相近的深灰与细边框；选中描边接近白色，生成与失败状态保留语义色。颜色、圆角等共用值放在 `ui-kit` 的主题变量里。

## 大图预览与视频播放

双击图片/视频媒体区，或选中一个媒体节点按 Space，打开全屏预览。输入框中 Space 保持输入行为。外部菜单可调用 canvas-ui 导出的 `openPreview(nodeId)`。左右切换按画布阅读顺序（80px 行容差），同步选中；关闭时恢复画布焦点，仅当节点在视口外才平滑居中。右侧详情开关保存在 `vis.preview.details`，`Lightbox` 的 `footer`（至少 96px）和 `details` 可注入版本条及扩展详情。

| 快捷键 | 行为 |
|---|---|
| Esc | 关闭预览 |
| Space | 打开预览；图片中关闭；视频中播放/暂停 |
| ← / → | 上一个 / 下一个媒体节点 |
| 0 / 1 | 图片适应窗口 / 100% |
| + / - | 图片放大 / 缩小 |
| 滚轮 / 触控板捏合 | 围绕指针缩放图片（10%–800%） |
| 双击图片 / 拖动图片 | 适应与 100% 切换 / 平移 |
| J / L | 视频后退 / 前进 5 秒 |
| , / . | 暂停并后退 / 前进 1/30 秒 |
| M | 视频静音切换 |

卡片视频默认显示首帧和时长，悬停显示播放按钮及进度条；卡片播放静音，离开视口自动暂停。预览视频自动播放，有声播放受浏览器限制时退回静音；支持缓冲进度、拖动跳转、音量、倍速、循环和浏览器全屏。暂停时控制栏常显，播放中鼠标静止两秒后隐藏。

预览通过页面顶层 portal 覆盖画布与会话面板，遮罩为 `rgba(10,10,11,.94)` 并模糊 6px。详情使用面板底色、左边框与 20px 内边距，标签 11px、值 13px，长素材 ID 以等宽字体保留首尾并在悬停时展示全文。详情展开时媒体在剩余区域居中，缩放徽标固定在媒体区右下角；适应窗口只缩小不放大（小图为 100%），手动缩放仍可放大。播放器与顶栏类型图标复用画布 SVG，播放器图标为 16px、1.5px 描边，音量滑条在悬停或键盘聚焦时展开。

当前 NodeView 没有标签及素材显示名，默认详情使用类型与短节点 ID、素材版本 ID；尺寸和时长读取媒体实际元数据。
## 右键菜单与复制粘贴

空白处右键可在指针位置新建文本、生图、生视频、上传或粘贴。节点右键提供复制、粘贴、创建副本、删除、作为参考发给 Agent、以选中节点为参考生成图片/视频及下载；右键未选中的节点会先单选它，已选中的节点保留当前多选。引用加入现有会话输入框并展开会话面板；参考生成放在选区右侧，沿用 ⊕ 的避让布局。

复制快照只保存在当前页面、当前空间的画布实例内，刷新或切换空间即清空；文本内容可同时写入系统剪贴板，节点粘贴只读取页面快照。Cmd/Ctrl+C、V、D 分别复制、粘贴和创建副本，input、textarea、可编辑区域保留浏览器行为。粘贴以最后指针位置或右键位置为选区左上角；副本相对原选区偏移 (40, 40)，操作后选中新节点。

每次粘贴只提交一个 canvas.apply：先创建全部节点，保留类型、尺寸、主槽位内容与 prompt，再用 tempId 绑定选区内参考，外部参考保留原节点 ID。素材只复用 assetVersionId，不复制文件；历史生成任务与修订不复制。沿用 canvas.apply 每批 200 个 op 的上限，超限时整批拒绝并显示错误，不拆成部分成功的粘贴。

菜单使用主题变量，贴近指针并限制在视口内；点外部、Esc、滚动画布或开始移动视口时关闭，菜单支持方向键和 Home/End 聚焦。子菜单在菜单内展开，以避免越过视口边缘。

图片和视频下载原始素材，宿主的 /assets/<space>/<id>?download=1 使用素材 displayName 设置 UTF-8 attachment 文件名，清理路径分隔符与控制字符，缺省使用类型与日期；普通预览和 Range 行为不变。文本下载 UTF-8 .txt，多选逐个发起下载；浏览器可能要求允许多个文件下载。

## 生成服务设置与模型选择

顶栏齿轮（Cmd/Ctrl+,）及提示词面板的“管理生成服务…”打开同一设置对话框。左侧列出内置只读服务与用户添加的火山方舟，右侧编辑名称、地址与图片/视频模型，底部设置默认模型。整份配置经共享 ProviderConfigSchema 校验并调用 providers.update。密钥独立保存，密码输入提交即清空，只显示 hasKey 状态，清除密钥与删除服务需确认；密钥不进入浏览器存储或配置。

连接建立及 events.providersChanged 后重新读取 providers.list；对话框有草稿时保留草稿并提示载入最新。提示词面板按媒体类型分组选择模型，依 paramsSchema 展示枚举、数值、布尔和字符串控件及默认值；不支持的形状跳过，开发环境警告。方舟尚无密钥时允许选择模型但禁用生成。正常生成请求由服务端读取目标节点的 provider、model 与 params；模型被删除时界面提示并显式提交已解析的默认模型与参数。

节点生成设置读自 NodeView.generation，经 canvas.apply 的 node.setGeneration 写入 space.db；完整节点事件使其他窗口及 Agent 的修改实时更新选择器。保存失败提示错误，不把浏览器缓存作为成功状态。新建生成节点优先用 localStorage 的 vis.gen.last.<kind>，再用全局 defaults，并随 node.create 入库；只有“上次使用”仍属于浏览器偏好，密钥不进入这些记录。

首次打开项目时，仅检查当前存在节点对应的旧 vis.gen.<spaceId>.<nodeId> 键。已有数据库设置优先，迁移写入通过 onlyIfUnset 在事务内检查空值；有效旧设置成功写入或确认数据库已有设置后删除旧键，失败保留待重试且不阻塞界面；其他项目及不存在节点的键不动。节点选择已移除模型时显示“模型已移除”，使用当前默认模型与其默认参数，不崩溃；没有可用模型时禁用生成。

复制、粘贴、创建副本携带节点设置；另存版本为节点也携带设置，仍不继承提示词及参考输入。同类型 ⊕ 快速延伸沿用源节点设置，跨类型延伸和多节点参考生成按目标类型的上次使用/默认值初始化。生成设置可用现有撤销/重做快捷键恢复。

## 版本历史

图片和视频主槽位在首次进入视口或选中时读取 `slot.history`，按槽位缓存在页面仓库。读取所有分页后按修订升序、素材版本 ID 去重，首次出现的位置确定 v1…vN；清空与文本修订不计数，恢复旧素材也不新增版本编号。`slot.revised` 使已请求槽位的缓存失效并重读，过期请求不覆盖新结果。标签显示当前素材编号/总数，只有一个版本时隐藏；文本仍显示修订号。新版本的未读点仅保存在本页，打开版本条视为已读。

单选且至少有两个素材版本时，在节点标签上方的 NodeToolbar 显示版本条，下方提示词面板保持原位。缩略图从左到右旧→新，外环标出卡片正在显示的版本（查看旧版本时外环移到该格），“当前”角标始终在当前版本；生成中在末尾追加占位格。超过八个可横向滚动，打开时滚动到当前版本。悬停 300ms 显示时间、模型/提供者与提示词前 60 字。VersionStrip 同时支持画布 52px 和预览 72px 缩略图，预览通过 Lightbox footer 接入同一版本 hook 和 store 历史缓存：至少两个版本才显示，左右切换节点同步切换版本条。预览内悬停窥视、单击固定查看及 `[` / `]` 切换只影响预览，画布保持主槽位内容；“设为当前”复用画布恢复动作及冲突处理，关闭预览清除临时查看状态。

悬停仅临时窥视素材，移开恢复；点击旧版本固定查看，节点变虚线框，底部显示版本编号、“设为当前”和“另存为节点”。恢复通过 `canvas.apply` 的 `slot.setAsset` 携带最新已知 `expectedRevision`，产生新修订而不重跑生成；冲突提示“节点内容刚更新，请重新选择”，刷新历史且不自动重试。另存复用素材 ID，在右侧按现有避让规则创建同类型同尺寸节点，不复制文件、不继承提示词和参考输入，成功后选中新节点。

点击当前版本、Esc、取消选择或画布空白退出查看；单选时 `[` / `]` 切换查看版本，查看旧版本时 Enter 恢复，输入框中不拦截。正在查看旧版本时收到新结果不打断查看，只更新历史与计数；通常显示当前内容时，新素材加载完毕后在旧素材上方做 400ms 淡入，避免闪白。

未决项：另存节点的命名。当前节点没有持久标签字段，本轮沿用类型名，不增加命名字段；待节点命名能力明确后再接入版本后缀。

## 会话改名

卡片标题可双击原地编辑；卡片头悬停或键盘聚焦时，在 chevron 左侧显示“⋯”菜单，包含“重命名”，用户命名时另有“交给 Agent 命名”。菜单沿用新建会话菜单的方向键、Enter、Esc 行为，点击菜单与编辑不会展开或收起卡片。

输入框继承标题字号并占满标题区，进入时自动全选。Enter 或失焦保存，Esc 取消；空白或未改动取消。编辑键盘事件不传播到卡片或画布快捷键。失败用现有通知提示并恢复原标题。

界面调用 `session.rename({ requestId, sessionId, title })`，trim 后长度 1–60，空串返回参数错误；成功将来源设为 user。`session.resetTitle({ requestId, sessionId })` 保留标题，来源恢复 default，让下一回合 Agent 重新命名。两者返回 SessionSummary，遵循 requestId 幂等规则并通过 session.updated 同步所有窗口。

Agent 名字带淡色小标记，title 为“由 Agent 命名”；Agent 更新标题时约 200ms 淡入，尊重 prefers-reduced-motion。用户名和默认名不显示标记，收起侧轨的首字与 title 随最新标题更新，新建默认名仍为“Codex N”等。


## 项目与工作区（2026-10-27）

顶栏提供项目切换与新建，按项目切换画布和会话，当前项目 ID 保存在 `vis.project`。这里的项目对应原有 Space，不增加第二套身份；项目持久保存本机根目录，默认位于 `$VIS_PROJECTS_DIR/<项目名>` 或 `~/visCreative/<项目名>`。

新建会话改用对话框，选择 Codex / DeepSeek、可选标题及默认或已有工作目录。已有目录可通过本机目录选择器选择，不支持的平台手动填写绝对路径；后台校验存在与可读写性。标题留空交由 Agent 在正常回合中命名；提供继续创建入口。项目入口打开共享素材目录，会话入口打开对应的本机工作目录；工作目录在重启及 resume 后保持不变。

输入区提供项目技能选择及 `/` 名称筛选，选中技能显示可移除标签，发送时以名称数组随消息持久化，在历史消息中继续显示。界面只显示技能元数据；每回合由适配器提供项目路径和目录，要求 Agent 对明确选择读取并遵循相应 `SKILL.md`。不扫描任意工作目录，也不把整份技能正文放进输入框。

文件系统 RPC、迁移、原生技能支持证据与本地媒体登记的权限边界见 [0008 · 项目、工作区与项目技能](0008-projects-and-workspaces.md)。项目切换不停止后台执行，目录选择不增加 Agent 的工具权限。
