# 0019 · 界面打磨（第一批）：降噪、主色与会话输入区

状态：已实现（2026-10-30）

日期：2026-10-30

基于 [0006](0006-web-ui.md)（网页界面与视觉风格）、[0015](0015-session-experience.md)（会话体验）与 [0016](0016-canvas-organization.md)（画布整理）。来源：维护者 2026-10-30 请 Claude 评审界面审美；评审截图在 `/tmp/vis-ui-review/shots/`。

## 背景

整体底子可以：深色、灰阶克制、圆角统一，右键菜单、@ 选择器和计划卡片已经成熟。观感不好主要来自两点：

1. **吵**：同一信息重复出现（项目名一屏 4 次），调试信息直接露出（节点版本号、工作目录路径、模型 ID 重复、React Flow 水印），操作提示常驻顶栏。
2. **不统一、没有主色**：主按钮和选中态都是灰色，「保存配置」「发送」看起来像禁用；两处发送按钮样式不同。

本批只做「改动集中、效果最明显」的部分。遮罩、关闭按钮、箭头图标、设置导航与卡片边框的统一放第二批。

## 决定

### 1. 主色

`theme.css` 的 `--vis-accent` 从灰色改为**靛蓝 `#7b7fff`**（维护者 2026-10-30 从靛蓝、青柠、黑白三张样张里选定），同时给出：

- `--vis-accent-soft`：`rgba(123, 127, 255, 0.18)`，用于选中底色；
- `--vis-on-accent`：主色上的文字色，白色；
- `--vis-focus`：输入焦点描边，等于主色。

主色只用在四处：主按钮、选中状态（节点边框、标签页、列表当前项）、输入焦点、与选中节点相关的连线高亮。其余仍是灰阶；状态色（成功 / 警告 / 危险）和 Agent 标识色不变。

全站只保留一种主按钮样式 `button.is-primary`（放进 `ui-kit/theme.css`，删掉三个包里各自的写法）。每个对话框最多一个主按钮：保存配置、确认开启、创建、发送、生成都改用它。

### 2. 顶栏与项目名

- 顶栏左侧：项目切换（现在在右侧面板头部，移过来），旁边一个连接状态小圆点；悬停显示「已连接 · 11 个节点 · 0 个生成中」。
- 顶栏右侧：运行中、今日用量、通知、设置，都是同样大小的图标按钮。今日用量改成图标按钮，悬停或点开再显示数字。
- 删除顶栏的操作提示「拖入图片或视频导入 · 选中后按 Delete 删除」：拖入导入放进空画布的引导，Delete 已在「?」快捷键面板里。
- 画布顶部居中的胶囊只保留「画布 / 看板」切换，去掉项目名。
- 右侧面板头部显示「会话」，不再是项目切换。
- 看板标题保留「工作看板」，去掉项目名副标题（当前项目 / 全部项目切换已经说明范围）。

### 3. 去掉露出的调试信息

| 位置 | 现在 | 改为 |
|---|---|---|
| 画布节点上方 | 类型小字「图片 / 文本」+ 版本号「r1」 | 默认隐藏；节点悬停或选中时显示类型；版本号只在版本历史里出现 |
| 看板卡片 | `workspaces/…` 路径、每张卡的「今日生成 0」 | 路径移到卡片菜单「在访达中显示」的悬停提示；今日生成为 0 时不显示 |
| 项目菜单 | 每个项目下一行完整路径 | 只显示名称；路径放悬停提示 |
| Skill 管理 | 弹窗正文的完整路径 | 移到「在访达中显示」按钮的悬停提示 |
| 设置 › 服务 | 「mock-image-1 mock-image-1」 | 显示名与 ID 相同时只显示一次 |
| 画布右下角 | React Flow 水印 | 隐藏（`proOptions.hideAttribution`；React Flow 为 MIT 许可，两份 README 的致谢里写明使用了 React Flow） |

### 4. 画布内容

- **文本节点渲染 Markdown**：非代码文本节点在只读状态用 react-markdown 渲染（禁用原始 HTML，沿用会话的配置），双击进入编辑时仍是原文。`@vis/canvas-ui` 需要新增 react-markdown 依赖，与 `@vis/workbench-ui` 同一版本，锁文件里已有，不引入新包。@ 选择器和其他摘要显示纯文本摘要（去掉 `#`、`**` 等标记）。
- **图片和视频不留灰边**：节点里的媒体铺满（`object-fit: cover`）。图片和视频节点的右键菜单加「按素材比例调整」：宽度不变，高度按素材宽高比，算普通的一步撤销；素材未加载或比例已一致时禁用。
  - 不在界面里自动调整：界面只能以用户身份写布局，每次都会记一步撤销，Agent 异步生成的素材会给用户插入不是自己做的撤销步骤。素材写入时按比例自动调整应由后端完成，涉及协议，放第二批单独设计。
- 底部工具栏统一成图标按钮：「整理」改成图标；「显示工作文档」改成可切换的图标按钮（按下态用主色底），文字放悬停提示。

### 5. 会话输入区（LUI）

重做成一张整体的输入卡片：

```
┌──────────────────────────────────────────────┐
│ [附件缩略图…]                                  │
│ 给 Agent 发消息，@ 引用节点                      │
│                                              │
│ ＋  Skill  每次询问  默认⌄              (↑)    │
└──────────────────────────────────────────────┘
```

- 卡片本身是输入框：焦点时整张卡片描主色边。
- 底部一行：左边是附件、Skill、权限、模型（模型选择从卡片上方移进来）；右边是圆形发送按钮，可发送时用主色，不可发送时灰色。回合运行中、输入框为空时，这个按钮变成停止；运行中输入框有草稿时仍是发送（排队，保留 0015 的点击排队），Enter 同样排队。
- 占位符缩短为「给 Agent 发消息，@ 引用节点，/ 选 Skill」；删掉卡片下方那行「回车发送 · Shift+回车换行」，放进发送按钮的悬停提示。排队提示（「本回合结束后发出」）仍显示在卡片下方，只在有排队时出现。
- 画布生成框的发送按钮换成同一个组件，两处样式一致。

### 6. 会话消息

- Agent 回复前加 Agent 图标与名称（Codex / DeepSeek），与用户消息的「你 · 时间」对称。
- 用户消息改为浅色底块（`--vis-node` 底、圆角），去掉左侧竖线；消息之间去掉分割线，用间距分组。
- 底部状态行与正在执行的工具行重复时只保留一处：有正在运行的工具行时，底部状态行只显示计时。
- 空会话不再只显示「已到最早」：显示 Agent 图标、一句说明和 3 条示例提问（点一下填入输入框，不直接发送）。「已到最早」只在确实向上翻到头时出现。
- 修复：思考过程展开、流式追加时，行与行重叠。
