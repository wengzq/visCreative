# Lessons

Pitfalls that cost someone time, grouped by area. Read the file for the area you are about to touch; when you hit a non-obvious pitfall, add an entry in the same change that fixes it (RFC 0042 §5).

Each entry gives the **symptom**, the **cause** and **what to do instead** in a few lines, and links the commit or RFC that found it. RFC findings sections stay where they are; copy a finding here when it applies beyond its RFC.
